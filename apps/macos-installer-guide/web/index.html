A practical installation guide

A bootable Mac installer. One verified step at a time.

Use Terminal for preparation, downloads and USB creation. Use startup options for the boot test. Each task ends with a concrete check.

You already have an IPSW? Read this first.

An .ipsw is a restore image, not the full installer app that createinstallmedia uses. Copying or extracting it onto a USB does not produce Apple’s bootable installer.

Route A · steps 01–09 I want a bootable USB Obtain the full installer app, then write it to a dedicated USB. Route B · no USB I want to use my IPSW Restore a compatible Apple-silicon Mac from another Mac, or use compatible virtualization software.
01

Identify the Mac and your file

Open Terminal. Commands work from any folder. Keep the same Terminal tab open: later steps reuse the variables you set. Run the hardware check on the Mac you will install onto; if it is a different Mac, record its model separately.

Terminal
sw_vers
sysctl -n hw.model
system_profiler SPHardwareDataType
Verify before continuing

Record the model and Chip or Processor. Check the intended macOS against Apple’s compatibility links. An IPSW belongs to the restore route below. A full installer app belongs to the USB route. Do not rename an IPSW to .app or write it to USB with dd.

02

Check your backup and supplies

Use a dedicated USB drive of 32 GB or larger, a compatible Mac, administrator access, power and internet. Copy anything you need off the USB. Back up the destination Mac before installation.

Terminal
tmutil latestbackup
df -h /
Verify before continuing

If using Time Machine, confirm the latest backup path and open a needed file from that backup. If no backup is reported, make and verify one first, or verify your other backup method. Confirm there is room for the full installer download; use its listed size in the next step. A backup path alone does not prove the backup is usable.

03

Get the full installer app

Already have a full installer in Applications? Skip the download and continue to step 4. Having an IPSW does not satisfy this step. First ask Apple which full installers this Mac can download.

Terminal
softwareupdate --list-full-installers
Verify before continuing

Choose an exact version from the output. If 27.0 is absent, do not assume it is available for this Mac. Use Apple’s download guidance for another supported method. Then run the separate download command below. Success means the download finished and an installer app is present in Applications. Quit it if it opens; do not start installation yet.

Download only after replacing the example version with one actually listed:

Terminal · edit the version first
installer_version="27.0"
softwareupdate --fetch-full-installer --full-installer-version "$installer_version"

Verify the download:

Terminal
find /Applications -maxdepth 1 -name 'Install macOS*.app' -print
04

Point Terminal at the installer

Copy the exact installer path from step 3 into the assignment below. The example follows Apple’s macOS 27 command; your installed app name is the source of truth.

Terminal · edit the path first
installer_app="/Applications/Install macOS 27 Golden Gate.app"
Verify before continuing
Terminal
test -d "$installer_app" && echo "PASS: app exists" || echo "STOP: app missing"
test -x "$installer_app/Contents/Resources/createinstallmedia" && echo "PASS: tool exists" || echo "STOP: full installer tool missing"

Both checks should print PASS. If either fails, fix the path or obtain the full installer. A file-size check by itself cannot establish that the download is complete.

05

Identify the USB — before erasing

Connect the dedicated USB. Inspect external physical disks, then replace diskN with its whole-disk identifier (for example disk4). Never choose the internal disk. Recheck identifiers after reconnecting a drive.

Terminal · replace diskN
diskutil list external physical
usb_disk="/dev/diskN"
diskutil info "$usb_disk"
Verify before continuing

Match the device name, capacity and External location to your USB. Confirm Whole is Yes. If the device is internal, ambiguous, or contains anything you need, stop. Record this identifier; do not guess from a previous session.

06

Prepare the USB volume

This creates a GUID partition map and a Mac OS Extended (Journaled) volume named MyVolume. Read the disk details again immediately before running the erase command.

Erases a whole disk

Erases the entire selected USB disk, including every partition. Run only after verifying step 5. This command has no interactive confirmation.

Terminal · erases disk
diskutil eraseDisk JHFS+ MyVolume GPT "$usb_disk"
Verify before continuing
Terminal
diskutil list "$usb_disk"
diskutil info /Volumes/MyVolume

Expect successful erase completion. Confirm GUID_partition_scheme, MyVolume, the expected capacity, and its location on the USB you selected. If any value is wrong, stop.

07

Write the bootable installer

Run the command, enter your administrator password, then read the target volume before typing Y. Password characters do not appear. Keep the USB connected until the tool finishes.

Erases the volume again

Confirm the prompt names your USB volume. Approve removable-volume access if macOS asks.

Terminal · erases volume
sudo "$installer_app/Contents/Resources/createinstallmedia" --volume /Volumes/MyVolume
Verify before continuing
Terminal · run immediately after
echo "createinstallmedia exit status: $?"

Wait for createinstallmedia to report that the install media is available. Immediately run the exit-status check shown here, before any other command: it should be 0. A nonzero status or any error means this step is incomplete; do not treat the existence of files on the USB as success.

08

Inspect and eject the finished USB

The volume is normally renamed to match the installer. Inspect the same physical disk; do not assume it is still called MyVolume.

Terminal
diskutil list "$usb_disk"
Verify before continuing

The renamed installer volume should appear on the intended USB. This confirms its location, not bootability. Eject with the command below and expect an ejected message before unplugging. Step 9 is the actual boot test.

Terminal
diskutil eject "$usb_disk"
09

Boot it and verify the installer opens

Connect the USB directly to the destination Mac and connect to the internet. Save open work and shut down. Apple silicon: hold the power button until startup options appear, select the installer and Continue. Intel: power on holding Option, select the installer and press Return.

Before you test

Run the verification command in Terminal after the installed system boots. Do not erase the internal disk just to test the USB. On T2 Macs, external boot may need enabling in Startup Security Utility.

Verify

The macOS installer or recovery utilities should open from the USB. Reaching this screen is the practical boot test. You can quit and restart without installing. If you choose to install, follow the onscreen prompts and select your intended destination volume. After setup, run sw_vers and compare ProductVersion with your intended version.

Terminal · after setup
sw_vers
Route B · existing download

Use the IPSW you already have

This route does not make a bootable USB. For a physical Apple-silicon Mac, an IPSW restore needs a second Mac and a direct data cable. An Intel T2 firmware restore is a different case; do not assume a macOS Apple-silicon IPSW applies to it.

B1Inspect the local file

Replace the path below with your existing file. No download is needed for this inspection.

Terminal · edit the path first
ipsw_file="$HOME/Downloads/your-file.ipsw"
ls -lh "$ipsw_file"
unzip -t "$ipsw_file"
Verify

The file exists and the archive test finishes without errors. This can take time on a large image. Archive integrity does not prove authenticity, compatibility or Apple signing eligibility. Match the exact device and build using IPSW.me · macOS 27.0 and the file’s original source. That index could not be retrieved during this guide’s source check; no current signing status is asserted.

B2Prepare the host and enter DFU

Follow Apple’s model-specific DFU instructions for the right port, cable and button sequence. The host needs macOS 14 or later and internet. Keep both Macs powered. The target’s display stays blank in DFU.

Verify

Finder on the host shows the target in Mac DFU Mode. A blank target screen alone is not evidence of DFU. If the Finder device does not appear, recheck Apple’s port and cable instructions before continuing.

B3Choose recovery or an erase-and-restore

For a broken Mac, Apple advises trying Revive first to preserve data. Apple’s current public Finder guide describes its managed restore flow; it does not document selecting your local IPSW on the page linked here. Do not assume clicking Restore automatically uses your downloaded file.

Erases the target Mac

Restore erases the target Mac. Back up first, and try Revive before Restore when data matters.

For a local-file workflow, consult the current Apple Configurator guide for your installed version. Proceed only when the restore UI identifies the intended target and accepts your exact compatible IPSW. This guide does not supply an unverified Terminal restore command.

Verify

Before confirming a restore, verify the target Mac, selected file and backup. After completion, the target restarts into setup; after setup, run sw_vers and compare version and build with your intended image. An error or a device remaining in DFU is not success.

For a virtual machine instead, see Apple’s macOS virtualization sample. Its command-line InstallationTool uses IPSW restore images to create a VM; it does not create USB media.

When a check fails

Troubleshooting

“Update not found”

Run softwareupdate --list-full-installers again. Use an exact listed version, or Apple’s download links on a compatible Mac. An IPSW listing does not guarantee availability as a full installer.

Missing createinstallmedia or invalid installer

Check the exact application path in step 4. An IPSW or incomplete installer is insufficient. Download the full installer from Apple again; do not bypass validation.

The USB cannot be erased or is busy

Close files and Finder windows using it. Re-run step 5 to confirm the disk identity before retrying preparation. Never switch to another disk identifier just to make the error disappear.

The installer is not in startup options

Connect directly, check compatibility, and repeat the boot sequence for the target hardware. For a T2 Mac, check Apple’s external-boot setting. If creation failed, recreate the USB only after rechecking its identity.
