# The tiny project notebook

An idea does not need to be big to be worth making.

## The idea

Build a **little reading corner** for useful pages and notes. Keep the files easy to move, easy to edit, and easy to understand.

## A simple checklist

- Choose a name.
- Sketch the smallest useful version.
- Make something you can try today.

## Example

```js
const smallThings = ['read', 'make', 'share'];
for (const thing of smallThings) {
  console.log(`Time to ${thing}.`);
}
```

Use `data/` as the home for your documents.
